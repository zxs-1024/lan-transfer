# 邻传

邻传（LAN Transfer）是一个用于 Chrome 的本地文件和文本分享扩展。它可以从电脑中选择文件、复制文本，也可以生成局域网二维码，让同一 Wi-Fi 下的手机扫码下载文件和复制文本。

Chrome 扩展不能自行监听局域网端口，所以本项目包含两个部分：

- `extension/`：Chrome Manifest V3 扩展，负责文件与文本管理、本地下载、二维码和分享链接。
- `server/`：只使用 Node.js 内置模块的本地助手，负责保存共享内容并提供手机页面。

## 安装和使用

需要 Chrome 和 Node.js 18 或更高版本。无需执行 `npm install`。

### 1. 启动本机助手

在 macOS 上双击 `start.command`，或在终端运行：

```bash
npm start
```

首次在 macOS 双击时，如果系统阻止运行，可右键 `start.command` 选择“打开”。保持这个终端窗口运行，关闭后手机链接和下载都会失效。

### 2. 加载 Chrome 扩展

1. 在 Chrome 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。
4. 将邻传固定到工具栏。

### 3. 分享文件和文本

打开扩展，点击“添加文件”或拖入文件。文件出现在列表后：

- 点击行末下载按钮，由 Chrome 将文件下载到默认下载目录。
- 点击“手机扫码取用”，让手机扫描二维码。
- 点击“复制链接”将局域网分享页发给同一 Wi-Fi 中的设备。

在“文本”输入框中粘贴内容，粘贴后会自动加入共享列表。手机打开同一个分享链接后，可在“共享文本”区域点击复制按钮。

删除按钮只会移除共享副本，不会删除电脑中的原文件。共享文件和文本保存在 `~/.lan-transfer/`。文本最多保留最近 20 条，单条不超过 20,000 个字符。

## 使用条件

- 手机和电脑必须连接同一个 Wi-Fi 或局域网，访客网络可能阻止设备互访。
- 电脑休眠、助手退出或防火墙阻止 Node.js 入站连接时，手机无法访问。
- 分享链接包含随机令牌，但局域网中拿到链接的人可以读取列表、下载文件和查看文本。不要把链接公开发布。
- 扩展只连接 `127.0.0.1:34567` 的管理接口，手机只能访问分享页，不能调用文件或文本管理接口。

## 常见问题

**扩展显示“本机助手未连接”**

确认 `npm start` 的窗口仍在运行，然后点击扩展中的“重试”。如果修改了默认端口，需要同时修改 `extension/popup.js` 中的 `API_BASE` 和 `extension/manifest.json` 中的 `host_permissions`。

**二维码出现但手机打不开**

确认手机连接的不是访客 Wi-Fi。扩展会显示多个局域网地址时，可以点击“预览”后尝试地址列表中其他网卡地址，并检查 macOS 防火墙是否允许 Node.js 接受传入连接。

**下载大文件**

服务端支持 HTTP Range 请求，下载过程不会将整个文件读入内存。浏览器下载管理器可以按需暂停和继续。
